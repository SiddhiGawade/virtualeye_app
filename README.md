# Virtual Eye

Virtual Eye is an Expo SDK 57 React Native application that works as a private camera assistant. It uses the phone camera, on-device ML Kit image labeling, speech, and voice commands to help describe the surrounding environment.

The camera and scene-labeling features require a native Android build. The web version is useful for checking the user interface, but it does not provide the complete native camera and ML functionality.

## Requirements

Install the following before running the application:

- Node.js and npm
- Visual Studio Code or another IDE
- Android Studio
- Android SDK and Android SDK Platform Tools
- An Android emulator or an Android phone with USB debugging enabled
- An arm64-compatible Android phone if using the provided APK

## Open the Project in the IDE

1. Open the project folder in Visual Studio Code or your preferred IDE.
2. Open the integrated terminal.
3. Make sure the terminal is located in the project root.
4. Install the project dependencies:

   ```bash
   npm install
   ```

## Run the App in the IDE

### Start the Expo development server

```bash
npm run start
```

This starts the Expo development server. The terminal displays the available development options.

### Run the web version

```bash
npm run web
```

The web version can be opened in a browser and is useful for checking the interface.

The web version does not provide the complete native camera and ML Kit behavior. For camera scanning and scene labeling, run the Android version instead.

### Run on an Android emulator or phone

Make sure an Android emulator is running or connect an Android phone with USB debugging enabled.

If the native Android folder does not exist, generate it with:

```bash
npx expo prebuild --platform android
```

Then run:

```bash
npm run android
```

This builds and launches the application on the connected Android emulator or device.

When the application asks for permission, allow access to the camera, microphone, and speech recognition as needed by the enabled features.

## Verify the Project

Run the TypeScript check:

```bash
npx tsc --noEmit
```

Verify that the Android JavaScript bundle exports successfully:

```bash
npx expo export --platform android
```

This project currently does not contain an automated test script.

## Build an Android APK Locally

The native Android files are generated by Expo and are not committed to the repository.

Generate the Android project if necessary:

```bash
npx expo prebuild --platform android
```

From the project root, build the arm64 release APK:

```powershell
cd android
.\gradlew.bat assembleRelease -PreactNativeArchitectures=arm64-v8a
cd ..
```

The generated release APK is normally located at:

```text
android\app\build\outputs\apk\release\app-release.apk
```

To create the installable APK filename in the project root:

```powershell
Copy-Item ".\android\app\build\outputs\apk\release\app-release.apk" ".\VirtualEye.apk"
```

The project may already contain an APK named `VirtualEye.apk` in the project root.

## Build an APK with EAS

The project includes an EAS preview profile configured to create an APK.

Run:

```bash
npm run build:android
```

This runs:

```bash
eas build --platform android --profile preview
```

The EAS preview profile is configured for internal Android APK distribution. An Expo/EAS account and internet access may be required.

## Install `VirtualEye.apk` on an Android Phone

### Method 1: Copy the APK to the phone

1. Locate `VirtualEye.apk` in the project folder.
2. Connect the Android phone to the computer with a USB cable.
3. Copy `VirtualEye.apk` to the phone's Downloads folder.
4. Open the Files application on the phone.
5. Tap `VirtualEye.apk`.
6. If Android asks for permission, allow the Files application to install unknown apps.
7. Tap **Install**.
8. Open **Virtual Eye** after the installation finishes.
9. Grant camera, microphone, and speech-recognition permissions when requested.

### Method 2: Install with ADB

Enable **Developer options** and **USB debugging** on the Android phone, then connect it to the computer.

Check that the phone is detected:

```powershell
adb devices
```

Install the APK:

```powershell
adb install -r ".\VirtualEye.apk"
```

After installation, open the Virtual Eye application on the phone and grant the requested permissions.

## Important Notes

- The Android application package name is `com.virtualeye.app`.
- The supplied arm64 APK requires an arm64-compatible Android device.
- The camera scans still frames periodically and uses on-device ML Kit image labeling.
- No vision API key or network caption service is required for scene labeling.
- The web preview is not a replacement for testing the native Android camera and ML features.
- If native configuration changes are made, regenerate the Android project and rebuild the application:

  ```bash
  npx expo prebuild --platform android
  npm run android
  ```
